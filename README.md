## 🏮 About Me

> *"Code like the city never sleeps, think like the stars never fade."* ✨

I'm **Carlos Yajie Fetizanan**, a developer who sees code as a canvas. I build **intuitive frontend experiences**, explore **AI & Machine Learning**, and I'm leveling up to become a **Full-Stack Engineer** who brings design and solid backend logic together.

- 🎓 College student focused on **Data Analytics & Machine Learning**
- 🔭 Currently building **[F1 Forecast Simulator](https://github.com/crlsyajie/F1-Forecast-Sim)**: XGBoost race predictions replayed on real circuit maps
